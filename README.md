
# Cubie A5E Custom OpenWrt

Custom OpenWrt firmware for Radxa Cubie A5E.

## Hardware

- SoC: Allwinner A527
- RAM: 1GB
- Storage: 64GB microSD
- Ethernet: Dual Gigabit
- WiFi: AIC8800D80

## Build

1. Open GitHub Actions.
2. Select Cubie A5E Custom Firmware.
3. Click Run workflow.
4. Wait for completion.
5. Download Cubie-A5E-OpenWrt artifact.

## Target

sunxi/cortexa53

## Device

radxa_cubie-a5e

## Important

WiFi driver integration is not yet included.
Verify hardware compatibility before flashing.
